# 池塘边的小院

一座乡间两层小楼及其周边（蓝顶车棚、菜园、鸡舍、池塘）的程序化三渲二微缩模型。按手绘平面图的布局与实拍照片的外观手工建模（车棚与主屋成 90°，外侧是前后两栋红瓦、灰瓦平房，再外侧是菜地与果园），属于风格化复刻，不是测绘精度。场景里没有人物，只有一条会摇尾巴的小狗；也不含车牌、门牌、品牌标识或任何地理坐标。

入口 `/yard/`，不在首页导航中列出，页面带 `noindex`；首页页脚的 `©` 是隐藏入口。复用 `/shrine/vendor/` 的 Three.js 0.170.0 与 MIT 许可，运行时和几何工具来自 threejs-diorama Skill。

拖动或方向键旋转，滚轮、双指或加减号缩放，Home 复位。仅小狗头尾有轻微动画，减少动态效果时静止；离屏或隐藏时停止绘制。静态物件按材质合并。

用静态 HTTP 服务从站点根目录打开，无构建步骤；不能用 file:// 直接打开模块页面。
