# 百页行 · AI 互动小说

游戏大厅 `/games/` 的首个分区为「百页行 · AI 互动小说」，统一进入 `/games/fiction/` 剧本书架。当前四篇：《深入图书馆》《阿拉穆尔的亡魂》《再见，流星》《门后的火光》；《蛇墓余火》保持下架。

## 导航与内容

书架卡片进入对应 `/games/fiction/<story>/` 介绍页，提供无剧透梗概、玩法范围、存档边界、来源许可和游玩入口。前三篇在各自的 `play/` 子页游玩；《门后的火光》沿用 `/games/lantern-tomb-lab/`。各篇独立保存进度。

`games/fiction/shelf.css` 管理书架、介绍与来源页；`adventure.css` 管理游玩页的深色阅读面板，叠加在原有 `games/lantern-tomb/style.css` 上。`background.css` 仅在栏目首页最后加载，用于小恶魔图书馆背景与首页配色。剧本介绍和来源页恢复此前的月下遗迹背景，前三篇游玩页恢复各自深色阅读样式；旧门后试玩页及其来源页恢复纸色与原 SVG 插图。背景是静态装饰，不调用模型、不创建会话；本轮未修改 API、Cookie、存档或主持规则。

首页为「百页行」远景首屏与剧本列表；“选一篇，走进故事”锚点跳到列表。导航与游戏大厅入口使用新名称。每篇保留此前的独立主题与阅读样式。当前不加载动态预览的 Canvas 或 Live2D。

## 素材与响应式

`assets/baiyexing-library.webp` 为用户选定的小恶魔远景图书馆背景：整理图书时妖风卷起书页，人物是远处的小小背影。`assets/baiyexing-library-mobile.webp` 为同图的 3:4 竖向裁切；700px 以下使用。图片经 GPT Image 2.5 Sunburst 请求生成，属于东方 Project 小恶魔题材的生成二次创作，不是原剧本插图或玩法截图，也不纳入剧本文字的 CC 许可。

原图、参考来源、提示词与生成记录保存在本机 `/mnt/e/PG/imGen/2026-09-21-baiyexing/`，批准版本为 `baiyexing-wide-v2.png`；原图 1672×941。线上仅发布压缩 WebP，不上传本机请求记录。

首页背景是固定装饰层，无额外 JavaScript 或持续动画。书架首页留足高度展示场景，手机保留远处人物；本次背景不延伸到各剧本内部。系统减少动态效果时禁用继承的平滑滚动。

## 后续维护

`scripts/build-adventure-pages.mjs` 从剧本数据和门后试玩模板生成前三篇介绍、来源及游玩页；模板与生成器保留剧本原有背景，重新生成不会将首页小恶魔背景带入子页。新剧本添加后同步书架与大厅实际数量。

大厅自身继续使用原桌游静物与联机区样式，本轮仅同步小说入口的名称、图片和四篇数量。`assets/archive-night.webp` 继续作为剧本介绍与来源页的背景。

## 游玩页装饰与新开场 · 2026-09-21

首页标题在“百”与“页”之间额外增加 `0.5em` 间距；只作用于大标题。游玩页新增独立 `play-atmosphere.css`，图书馆用星仪/书页线刻，阿拉穆尔用罗盘/海图线刻，流星号用轨道/舱图线刻。素材为本项目 SVG 装饰，不是真实可探索地图，不含隐藏路线；不加载首页小恶魔背景。门后试玩沿用浅色纸面，以低对比线刻点缀。无新增脚本、依赖或持续动画。

四篇的开场约 500 字、四段，包含身份/委托、当前已知处境、随身物品和退路、可尝试的第一步。只在新建冒险时使用；旧进度的日志原样保留。前三篇的介绍页与公开 scenario.json 随生成器同步。
