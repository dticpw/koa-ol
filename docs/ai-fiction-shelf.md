# 百页行 · AI 互动小说

游戏大厅 `/games/` 的首个分区为「百页行 · AI 互动小说」，统一进入 `/games/fiction/` 剧本书架。当前四篇：《深入图书馆》《阿拉穆尔的亡魂》《再见，流星》《门后的火光》；《蛇墓余火》保持下架。

## 导航与内容

书架卡片进入对应 `/games/fiction/<story>/` 介绍页，提供无剧透梗概、玩法范围、存档边界、来源许可和游玩入口。前三篇在各自的 `play/` 子页游玩；《门后的火光》沿用 `/games/lantern-tomb-lab/`。各篇独立保存进度。

`games/fiction/shelf.css` 管理书架、介绍与来源页；`adventure.css` 管理游玩页的深色阅读面板，叠加在原有 `games/lantern-tomb/style.css` 上。`background.css` 最后加载，统一图书馆背景、文字遮罩与栏目配色。旧门后试玩页及其来源页也接入相同主题。背景是静态装饰，不调用模型、不创建会话；本轮未修改 API、Cookie、存档或主持规则。

首页为「百页行」远景首屏与剧本列表；“选一篇，走进故事”锚点跳到列表。导航与游戏大厅入口使用新名称。每篇封面保留独立主题插画，正文与表单置于深色面板，避免背景干扰阅读。当前不加载动态预览的 Canvas 或 Live2D。

## 素材与响应式

`assets/baiyexing-library.webp` 为用户选定的小恶魔远景图书馆背景：整理图书时妖风卷起书页，人物是远处的小小背影。`assets/baiyexing-library-mobile.webp` 为同图的 3:4 竖向裁切；700px 以下使用。图片经 GPT Image 2.5 Sunburst 请求生成，属于东方 Project 小恶魔题材的生成二次创作，不是原剧本插图或玩法截图，也不纳入剧本文字的 CC 许可。

原图、参考来源、提示词与生成记录保存在本机 `/mnt/e/PG/imGen/2026-09-21-baiyexing/`，批准版本为 `baiyexing-wide-v2.png`；原图 1672×941。线上仅发布压缩 WebP，不上传本机请求记录。

背景是固定装饰层，无额外 JavaScript 或持续动画。书架首页留足高度展示场景，手机保留远处人物；介绍和游玩页增加内容面板。系统减少动态效果时禁用继承的平滑滚动。

## 后续维护

`scripts/build-adventure-pages.mjs` 从剧本数据和门后试玩模板生成前三篇介绍、来源及游玩页；模板和生成器均保留统一背景引用，重新生成不会丢失主题。新剧本添加后同步书架与大厅实际数量。

大厅自身继续使用原桌游静物与联机区样式，本轮仅同步小说入口的名称、图片和四篇数量。`assets/archive-night.webp` 作为历史资产保留，现有小说页面不再引用它作为有效背景。
