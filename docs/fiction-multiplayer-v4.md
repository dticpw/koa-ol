# 多人主持 v4：按行动边界停轮，容纳不同玩法

本版在同场多人模式中调整节奏与主持控场，新局默认cooperative-v4。v3解释器、剧本原稿资料和旧存档本次保持原样；v4仍使用第3版存档结构及prisoner-13-v3剧本适配器，hostRevision单独固定为cooperative-v4。版本号不是存储格式升级。

项目仍在封测阶段。2026-09-23用户明确不要求兼顾旧版本存档恢复；后续结构与存储演进不以跨版本兼容作为发布门槛。本次保留已经存在的版本代码，主要用于复现对照与回退，不代表长期兼容承诺。

## 行动边界

取消每轮最多3段相邻路径的剧情限制。完整路线仍检查起终点、真实相邻连接和每位队员的同行授权；64个路径节点只作异常输出容量保护。上下文补齐通向远处目标的路径，完整地图也附各中间地点的限制，不能因放宽移动而遗漏门禁、反魔法或实际危险。

新增turnEnd，记录本轮是完成声明、遇到新选择还是被实际情况打断及原因。它供复核与事件记录使用，不显示为玩家需要操作的技术字段。普通交接、换房间、字数不足或“下一程就到”不能独立构成停轮理由；新风险、重要代价、条件失败和同伴不同意仍应停下。只询问不等于接受交易，正常回程也不等于同意新的风险。

正文按信息与互动需要伸缩，去掉300—600字的固定建议；输出token和保存容量仍有技术上限。不会为凑篇幅重复清点，也不为缩短故事跳过玩家的角色扮演。

## 不高效也可以是有效体验

闲聊、开玩笑、取外号、逞强、犹豫和情感互动应得到具体回应，不被偷换成侦查或强塞关键线索。新增roleplay结果类别，得到真实回应的角色扮演计入关注记录，不被误视为无人照顾。轮数和任务进度不触发机械处罚。

帮倒忙按物性、在场目击者、NPC性格和既有风险产生相称后果：小意外可以善后，实际报警也不能被当成无害玩笑抹掉。一人的行为不吞掉其他人独立可做的行动；不能替同伴交物、移动、反击或答应交易。只有实际打断才中止其他行动。

外号、乌龙、关系与承诺只在有后续意义时存入既有记忆类型，不为每个笑话建立永久状态字段。event以实际outcome为主要来源，可附玩家action作背景；单独意图仍不能证明已经发生。来源引用存在也不证明内容真实，语义一致仍依赖模型复核与实际评测。全队原地时不消费跟随授权，新约定独立核验后供后续移动使用。

## 测试与发布

固定快照对照v3和v4，覆盖旧局长路线、真实新危险、纯角色扮演、意外善后、真实警报、队友物品冲突、自愿闲聊、拒绝同行和尴尬后的求助。包含合成情境与明确标注的旧局测试转换，不迁移生产存档。程序断言只能验证位置、物品等底线，不能代替阅读正文。

一个独立玩家模型模拟三位角色进行连续冒险：友善的青禾、谨慎的墨川和爱玩的阿铃。玩家只读公开叙述及随身物品，预先约定在部分轮次加入闲聊、轻率尝试、分歧和回忆；这些提示仅决定玩家意愿，不指定主持必须成功或失败。分阶段盲评检查角色扮演、后果比例、参与机会、自主性、节奏和记忆。模型模拟不等于真人团，也不能以更少轮数直接证明体验更好。

候选B的三人新局共21轮，选择放弃账册交易并实际撤离，没有取得开锁方法；第1轮借来的铅笔在离场时归还。另以真实警报定点结果为种子连续续测至第8轮，验证承认失误、同伴不满、正式误报记录与恢复普通工作；该分支截止时没有离场。10类定点场景均有符合预期的B响应，但首次有2次复核超时，复测与原失败分别保留。主线有2次主持复核超时和1次玩家模拟器超时，恢复后完成；成功主持回合中位73.756秒。

仍有已知限制：第14轮把办公室文件柜及机械锁当成地图可知信息提前告知玩家；个别定点回程对子物品交接终点不够忠实；剧本没有明确厨师长性别，合成样本偶有漂移。盲评多集中于高分，不能代替真人体验结论，也不能证明所有方面都优于v3。详情与独立因果审核见资源库records/multiplayer-v4-20260923/REPORT.md。

本次便捷回退可将FICTION_MULTIPLAYER_HOST_REVISION设为cooperative-v3并重新部署，或同时修改host.js和service.js的新局默认值。它只选择后续新局的主持。封测期间如后续需要不兼容的格式演进，应明确告知影响，而不为旧存档长期维护双重语义。候选失败、中断、重试和完整结局分别记录，不拼成一次无失败通关。
