## 交互

首屏中央遮罩展开（1.45 秒，可点击中断）；场景题签随鼠标轻移；卡片局部高光跟随指针，进入或键盘聚焦时单次脉动；项目区由纸色切换深青色，桌面前三张卡片滚动层叠，手机自然纵向排列。卡片图形为装饰示意，不是真实产品操作录屏。

持续滚动更新通过按需 RAF 合并，隐藏页面取消 RAF，恢复时更新；既有模型离屏暂停机制复用。减少动态效果停用入场、脉动、位移、层叠和 CSS 动画，正文直接可见。无新依赖或外部素材。
