# 主持裁量：可靠结算与游玩体验

本轮维持“裁定 → 程序结算 → 语义复核并叙述 → 原子保存”的两次模型调用结构。正式冒险与实验墓室共用 `fiction-discretion.js`，不引入通用物理字段表、性别化待遇或新的倒计时。

## 行为边界

| 情况 | 期望行为 |
| --- | --- |
| 连贯操作含必要准备 | 直接承接；只有重要前提或风险变化才停下 |
| 初次求助 | 指出已有或可见的关键线索及用途 |
| 反复求助、明确索要操作方法 | 给具体可行步骤；不重复询问是否需要提示 |
| 请求对普通障碍通融 | 接受合理等价方法、省略重复劳动；实际便利仍结算 |
| 求助但未选择重大代价 | 不代花稀有资源、不代选牺牲、不替玩家完成交易 |
| 明确离场，曾委托顺路还借物 | 无新风险/代价时先实际归还再结束，不再索要专门口令 |
| 旧委托已取消或现在需冒险绕路 | 不自动执行、不假称完成、不凭空扣坏结局 |
| 结局回顾 | 根据最新事实与真实事件收束，不把旧优势当永久效果 |

顺手收尾必须有原授权、当前可行性和本轮实际结算。它不适用于未决定的重大交易，也不授权叙述者在复核之后新增动作。引擎继续检查地图、来源、位置、成就、结局条件与记忆献祭授权；一般物性、提示质量和语义上的授权仍依赖模型判断。

## 上下文与存档

`world.commitmentLedger` 从现有 `memoryJournal` 的最新状态确定性生成，最多16条，保留来源和兑现/取消证据；优先12条有效计划/约定、4条已处理事项，剩余名额按最新更新补齐。`total` 与 `complete` 明示覆盖情况。它补充关键词检索，不声称穷尽所有待办。

`fulfilled` 只能引用本轮已执行步骤中的逐字观察，不能仅引用玩家本轮“打算做”的声明。确认以前已完成的事情可以提供观察，不要求重复操作。逐字引用校验不能替代语义复核。

无需数据库迁移，不重置游客存档；新规则从下一次调用生效。旧存档原文与状态不重写，已结束冒险不强制重新开启。回退使用本次发布提交的 revert，保留数据库。

## 可复现验证

确定性回归：在支持 `node:sqlite` 的 Node 环境运行 `node --test tests/fiction*.test.mjs`。新增测试覆盖真实归还与离场、完成证据、未执行步骤、取消记录、有界账目、旧存档兼容和复核拒绝时不提交。

真实模型：通过已授权凭据入口向进程传入 `UPSTREAM_API_KEY` 与 `UPSTREAM_BASE_URL`，运行：

```sh
node scripts/eval-fiction-discretion.mjs /path/to/task-artifacts/candidate
```

该命令会调用现有 `gpt-5.6-sol` 主持，产生费用，并在指定目录保存合成试玩、请求/响应及本地预算统计；不会访问游客存档。可在目录之后附案例ID筛选。`FICTION_EVAL_ROOT` 可指向旧版源码快照，以同一数据集对照。每次运行使用独立输出目录，保留失败证据。预算数值沿用应用估算，不作为供应商账单。

案例使用原创微型场景《渡口告别》、正式《深入图书馆》及实验墓室：三次重复顺手归还、取消委托、危险绕路、未决定的贵重赠送、连续三轮渐进帮助与实际操作、央求但未授权记忆牺牲、墓室安全探索求助。构造检查点不等于完整长篇通关。

状态断言之外，逐条语义复核四项，每项0—2分：

1. 意图与自主权：回应目的，没有擅自执行重大选择。
2. 帮助与节奏：提示具体、逐步更明确，没有无意义确认和重复劳动。
3. 一致性与信息边界：位置、资源、授权、知识和结局与结算一致。
4. 体验与收束：语气自然、失败留有可行路径，尾声不审判琐事。

任一重大越权、泄密或虚假完成即失败，不能靠其他项高分抵消。HTTP成功、自动状态断言通过、正文好看是不同证据。网络超时单列，不能算主持决策错误，也不能从样本中删除后只报告成功。

完整运行记录保存在本次任务产物目录，结论应注明样本与重试范围。此测试不证明长篇记忆、所有NPC动机或所有自然语言资源变更已经可靠。

方法参考：[OpenAI 评测指南](https://developers.openai.com/api/docs/guides/evaluation-best-practices#design-your-eval-process)：针对具体任务定义标准，覆盖典型/边界/对抗案例，比较版本并持续加入实际失败。

## 本次验证结果（2026-09-21）

- 最终确定性测试105项通过，Functions构建成功。
- 新规则初版11次真实模型行动、叙述调整后6次重点重测，全部通过状态断言，均未触发内部重裁。合计17次，包含构造检查点和三轮连续求助，不能称作17场完整冒险。
- 旧版对照首次5次尝试中有1次模型服务失败；保留该记录后，重新执行三轮求助链均成功。旧版在还牌及提示场景也能做对，样本未证明新版成功率显著提高。
- 实现者逐条检查新版正文：未发现代献记忆、赠送重要物件、危险绕路或虚假归还；提示能从线索推进到操作。此为实现者复核，并非独立盲评或真人体验评分。
- 仍有说明规则、提醒未发生事项的措辞。增加叙述约束后部分改善，但没有完全消除，后续需结合真实游玩反馈调整。
