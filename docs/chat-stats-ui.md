# Chat 与 Stats 界面 · 2026-09-11

本轮采用主页 AI Chat 章节现有的深绿、浅柠檬色与星形元素，使用 Open Design 页面流程和专项动效流程完成本地实现。没有另建品牌或覆盖其他子项目的共享样式。

## 文件与功能

- `chat/index.html`、`assets/conversation/chat.{css,js}`：固定输入区、独立滚动消息区、三模型选择、开场草稿、新对话、附件、错误重试草稿恢复、代码复制/下载。网页入口仍为 `/api/chat`。
- `stats/index.html`、`assets/conversation/stats.{css,js}`：私有密码门、六项累计指标、近 30 天请求/token 趋势、累计模型 token 分布、最近 20 条模型筛选，以及原有 IP/国家/每日明细。无数据和刷新失败有独立状态。
- `functions/api/stats.js`：新增 `per_model` 返回字段，从现有 `chat_logs` 按模型分组求和。没有数据库迁移，不合并或删除旧模型历史。不从最近 20 条推算累计用量。
- `assets/conversation/studio.css`：仅由 Chat、Stats 使用的共享页面基础，未修改原 `design-system.css`。
- `assets/conversation/transition.{css,js}`：主页、Chat、Stats 同源跨文档过渡。星形共享元素从主页移动到侧栏，页面短淡变。保持原生链接，不拦截点击、不人为延迟网络请求。减少动态效果时跳过过渡；不支持原生过渡的浏览器使用简短入场降级。

日期趋势使用 UTC，自当天往前展示 30 个日历日，缺失日期填零。累计指标不受趋势按钮或最近记录筛选影响，界面已标明各自范围。Tokens 为接口返回计数，不是账单金额。

### GPT 联网搜索（2026-09-11）

网页 GPT 默认开启“联网”，允许模型按需使用上游 Responses 的 `web_search` 工具；关闭后不传工具。DeepSeek、Qwen 不启用搜索。`/api/chat` 只接受布尔值 `web_search: true`，服务端固定工具配置，不透传任意客户端工具。

响应新增 `web_search`（requested、已完成调用数 calls）和 `citations`（全文偏移、URL、标题）。界面依据真实调用显示“已联网检索”或“本次未调用搜索”，内联引用只允许 HTTP(S) 链接，保留代码复制与下载。当前为非流式回复，不显示实时搜索步骤。

Stats 继续记录上游返回的 token 用量，尚不单独统计搜索次数或搜索费用。已通过真实上游搜索探测、模型隔离/关闭/引用校验测试，以及 1440/900/390/360 宽度的浏览器检查。

### 等待反馈、流式回复与本机历史（2026-09-11）

网页发送 `stream: true`，后端统一输出 SSE `status`、`delta`、`done`、`error` 事件。GPT 使用 Responses 流，DeepSeek/Qwen 使用 Chat Completions 流并请求最终 usage。旧的非流式 API 请求继续可用。搜索状态来自实际工具事件，不转发上游推理正文。收到文字后立即显示，完成时渲染引用、代码块、总耗时与首字耗时。

输入区发送按钮在运行时变成停止按钮；取消会终止浏览器接收并向上游 fetch 发出 AbortSignal。保留未完成片段并标记，重试替换对应尝试而不重复问题。断流或 incomplete 事件不能算成功。D1 继续记 usage：取消为 cancelled，中断为 stream_error；没有最终 usage 的取消记录不代表实际零费用，上游是否即时停止计费无法由网页保证。

历史保存到各自浏览器 IndexedDB，包含对话、附件、引用与计时。新对话保留旧记录，历史弹窗支持恢复和删除，存储失败有可见提示。当前没有账号同步与云端对话备份；清理网站数据会删除本机记录。原有服务端 Stats 日志独立于本机历史。
### 城市归属地（2026-09-22）

- Chat 和 Responses 代理日志新增 `city` / `region`，仅从 Cloudflare `request.cf` 读取，不信任客户端自填的城市 header。无需调用第三方 IP 查询服务；元数据缺失写入 NULL。
- 最近调用显示当次请求的位置；访问来源保留原有 IP + 国家分组、次数和 token 汇总，位置取该组最近一条记录。最新记录缺失城市时不借用更早的位置。国家分布维持原统计口径。
