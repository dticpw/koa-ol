# Chat 与 Stats 界面 · 2026-09-11

本轮采用主页 AI Chat 章节现有的深绿、浅柠檬色与星形元素，使用 Open Design 页面流程和专项动效流程完成本地实现。没有另建品牌或覆盖其他子项目的共享样式。

## 文件与功能

- `chat/index.html`、`assets/conversation/chat.{css,js}`：固定输入区、独立滚动消息区、三模型选择、开场草稿、新对话、附件、错误重试草稿恢复、代码复制/下载。网页入口仍为 `/api/chat`。
- `stats/index.html`、`assets/conversation/stats.{css,js}`：私有密码门、六项累计指标、近 30 天请求/token 趋势、累计模型 token 分布、最近 20 条模型筛选，以及原有 IP/国家/每日明细。无数据和刷新失败有独立状态。
- `functions/api/stats.js`：新增 `per_model` 返回字段，从现有 `chat_logs` 按模型分组求和。没有数据库迁移，不合并或删除旧模型历史。不从最近 20 条推算累计用量。
- `assets/conversation/studio.css`：仅由 Chat、Stats 使用的共享页面基础，未修改原 `design-system.css`。
- `assets/conversation/transition.{css,js}`：主页、Chat、Stats 同源跨文档过渡。星形共享元素从主页移动到侧栏，页面短淡变。保持原生链接，不拦截点击、不人为延迟网络请求。减少动态效果时跳过过渡；不支持原生过渡的浏览器使用简短入场降级。

日期趋势使用 UTC，自当天往前展示 30 个日历日，缺失日期填零。累计指标不受趋势按钮或最近记录筛选影响，界面已标明各自范围。Tokens 为接口返回计数，不是账单金额。

## 验证

- 14 项后端测试通过，包含此前三模型/外部 GPT 限定测试，以及新增 Stats 鉴权、真实聚合查询和旧数据集保留检查。
- Chrome + Playwright 检查 1440、900、390px 布局；额外检查 360×640 小屏。无页面级横向溢出。
- 验证了模型选择、开场草稿、等待状态、失败草稿保留、新对话、代码下载、附件能力提示、重复发送防护、密码门、模型筛选、趋势指标切换、空数据、刷新失败和退出。
- 实际捕捉了原生 `pagereveal` 的 `viewTransition`，保存过渡前、中、后截图；检查浏览器后退和减少动态效果。
- 本轮 UI 验证使用明确标注的模拟回复和统计；未为视觉测试调用付费模型，未把测试数据放进网站源码。
