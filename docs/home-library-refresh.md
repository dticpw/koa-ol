# muQ 首页展示更新 · 2026-09-11

主页改为「庭院 → muQ 图书馆 → AI Chat / Games → Stats → 关于」的内容顺序。Multi-Agent、Galgame 与 Captcha Test 的首页介绍、链接及专用展示样式移除，子项目目录保留。

muQ 为首屏之后的独立重点区域，首屏按钮和导航均能直达。左右分栏承载原有档案内容与红魔馆图书馆微缩模型。手机转为上下布局，平板断点避免标题与神社相互遮挡。替换旧项目粘性堆叠和滚动全站换色，保留轻量入场与明确悬停反馈。

参考：https://kb.hth-ai.com/e/frontend-lab/hth-home/index.html 。通过用户授权的浏览器标签页实测参考首页与重点项目：采用简短大标题、文字与主视觉分栏、主次入口层级；继续使用 Koa-OL 的暖纸色与原有幻想乡模型，不复制参考站的图片、身份、项目或运行指标。

## 模型

`/library-scene/` 提供独立旋转/缩放；主页通过同源 iframe 按需加载。复用 `/shrine/vendor/` 的 Three.js 0.170.0 及 MIT 许可。静态预览约 72 KiB；1157 个静态网格合并为 17 个批次，完整场景约 19 次绘制调用、18471 个三角形。默认不自动旋转。

## 验证

- Chrome 桌面 1440、超宽 1920、平板 820、手机模拟 390 像素宽度；无横向溢出或缺图。820 宽首屏由实图发现标题遮挡并修正。
- 首页文本、链接与元描述中不再展示三个移除项目；muQ 先于其他项目。
- 图书馆、模型、AI Chat、Games、Stats 与预览图片 HTTP 200。
- 模型首帧就绪、鼠标与键盘旋转、独立缩放、Home 复位、离屏暂停、context loss 恢复；嵌入区域的鼠标滚轮仍滚动主页。
- 模拟减少动态效果；无新增页面 JS 异常。手机检查为浏览器视口模拟，未测试真机 GPU 和触摸。
