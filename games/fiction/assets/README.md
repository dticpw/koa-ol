# 剧本封面

两张插画专为 Koa-OL 的 AI 互动小说书架生成，未使用参考站的图片。

- `light-beyond.webp`：门后的火光，雨夜的小墓门、普通油灯与门内黑暗。
- `serpent-tomb.webp`：蛇墓余火，蛇形石雕之间的深长墓道。

制作请求使用 GPT Image 2.5 Sunburst（第三方通道的请求模型名），1024 × 1536、high；发布副本用 Pillow 缩至 800 × 1200，WebP quality 86。原图和完整提示词保存在制作档案中，不随公开页面发布。

这些是氛围插画，不代表逐项复刻游戏地图或机关布局。旧游玩页自绘 SVG 仍保留。

## 矢量装饰

- `tabletop.svg`：自绘纸牌、骰子与虚线路径，用于游戏大厅标题区。
- `trail-map.svg`：自绘罗盘、等高线与探索路径，用于小说书架和介绍页背景。不是剧本地图，不包含机关提示。

两项均为轻量 SVG，无字体、外部依赖或持续动画。

## 夜景背景

- `game-night.webp`：纸牌、黄铜骰子、筹码与星仪，1600×533，75740 bytes。
- `archive-night.webp`：月下石拱、冷青薄雾与油灯，1600×686，79850 bytes。

两张各一次生成请求，使用已授权的 model-library 通道，请求模型名 `gpt-image-2.5-sunburst` / high。请求尺寸1536×1024，实际返回横幅尺寸分别为2172×724和1916×821；Pillow等比缩放至宽1600、WebP quality84。原图、提示词与请求记录保存在 `/mnt/e/PG/imGen/20260920-game-nocturne/`。模型名是客户端请求参数，不能独立证明第三方实际后端身份。背景是氛围场景，不是地图或玩法承诺。

早期 `tabletop.svg` 与 `trail-map.svg` 保留为素材历史，当前页面不再引用。
