# 剧本封面

两张插画专为 Koa-OL 的 AI 互动小说书架生成，未使用参考站的图片。

- `light-beyond.webp`：门后的火光，雨夜的小墓门、普通油灯与门内黑暗。
- `serpent-tomb.webp`：蛇墓余火，蛇形石雕之间的深长墓道。

制作请求使用 GPT Image 2.5 Sunburst（第三方通道的请求模型名），1024 × 1536、high；发布副本用 Pillow 缩至 800 × 1200，WebP quality 86。原图和完整提示词保存在制作档案中，不随公开页面发布。

这些是氛围插画，不代表逐项复刻游戏地图或机关布局。旧游玩页自绘 SVG 仍保留。

## 矢量装饰

- `tabletop.svg`：自绘纸牌、骰子与虚线路径，用于游戏大厅标题区。
- `trail-map.svg`：自绘罗盘、等高线与探索路径，用于小说书架和介绍页背景。不是剧本地图，不包含机关提示。

两项均为轻量 SVG，无字体、外部依赖或持续动画。
