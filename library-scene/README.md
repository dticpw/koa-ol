# 红魔馆的藏书室

东方 Project 红魔馆地下图书馆主题的非官方程序化同人微缩模型，并非原作场景的精确复原。无外部图片、下载模型或人物素材。

入口 `/library-scene/`；主页 `/#muq-library` 按需嵌入。复用 `/shrine/vendor/` 的 Three.js 0.170.0 与 MIT 许可，运行时和几何工具来自 threejs-diorama Skill。

拖动或方向键旋转，Home 复位。独立页支持滚轮、双指、加减号缩放；主页内滚轮与纵向触摸留给页面。画面没有持续装饰动画，隐藏或离屏停止绘制，WebGL 失败保留实拍预览。静态物件按材质合并。

本地验证：Chrome 扩展连接；1440×1000 和 390×844 主页无横向溢出；默认、侧面、背面、低角度截图；鼠标旋转、键盘旋转/缩放/复位；离屏暂停和恢复；约 19 次绘制调用。手机是模拟视口，未测试真实手机触摸。随本次主页更新发布；线上状态以实际部署验收为准。

用静态 HTTP 服务从站点根目录打开即可，无构建步骤。不能用 file:// 直接打开模块页面。
